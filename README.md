# Unidac Industries

Estrutura profissional simplificada:

```
/
  index.html          # Login
  dashboard.html      # Painel
  *.html              # Demais páginas
  css/                # Todos os estilos
  js/                 # Todos os scripts
```

Login redireciona para `dashboard.html`.
Páginas exclusivas: `usuarios.html`, `inteligente.html` (admin), `ficha.html` (aluno).
